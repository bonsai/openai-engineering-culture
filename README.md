# openai-engineering-culture

Agent skill encoding OpenAI-style engineering and research culture.

## What this skill does

- Boundaryless / full-stack ownership (researchers debug k8s, infra people understand models)
- Bottom-up ideation with a high bar for validation
- Ideas are cheap; prototypes, evals, and data are valuable
- Highest organizational leverage = reducing experiment friction
- Start from user problems and work backward

## Usage

Drop `SKILL.md` into an agent skills directory (e.g. `.grok/skills/openai-engineering-culture/`).

The skill activates on topics around AI team culture, full-stack AI development, experiment-driven workflows, and cross-functional collaboration.

## Source

Distilled from public reflections of a new-grad engineer after one year at OpenAI.
